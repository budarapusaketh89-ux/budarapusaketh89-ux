## 🚀 Featured Projects

### 🩺 Medical Chatbot
Upload a medical PDF report and ask questions about it. The chatbot retrieves the most relevant passages from the document to answer.
**Tech:** Python, BioBERT, MiniLM, FAISS, MySQL
🔗 [View Repo](https://github.com/budarapusaketh89-ux/medical-chatbot)

### 🎧 Audio Event Classification
Classifies audio events using Wav2Vec2 with attention-based temporal pooling, trained on the Generic Audio Samples dataset from Kaggle. Co-authored a research paper on this work.
**Tech:** Python, PyTorch, Wav2Vec2
🔗 [View Repo](https://github.com/budarapusaketh89-ux/audio-event-classification)

### 📧 Spam Email Classifier
Classifies messages as spam or not spam with ~97% accuracy on the SMS Spam Collection dataset, served through a Flask web app.
**Tech:** Python, scikit-learn, Logistic Regression, TF-IDF, Flask
🔗 [View Repo](https://github.com/budarapusaketh89-ux/Spam-email-classifier)
